How do I get a token? (1 minute)
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Name it e.g. birthday-admin and pick an expiration.
  3. Repository access → Only select repositories → choose this repo.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Click Generate token, copy it and paste it above.

ghp_… classic tokens also work when they have the repo scope. Your token is only stored in this browser and is only ever sent to api.github.com.
